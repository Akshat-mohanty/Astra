# Astra — The Universal Workspace

Official waitlist landing page for **Astra Browser** ([Astra](https://github.com/Akshat-mohanty/Astra)).

## Live Deployment on Vercel

This repository is ready to deploy directly on **Vercel** with zero configuration:

- **Root (`/`)**: Astra Waitlist landing page with dark canvas, Geist Pixel typography, interactive viewfinder reticle focus effect, and alpha waitlist modal dialog.

## Local Development

```bash
# Using npx serve
npx serve . -l 3000

# Or using Python
python3 -m http.server 3000
```
